# Security policy

This package decides whether optional scripts run and what a visitor's consent cookie says, so a
defect here is a privacy problem. Please report suspected vulnerabilities privately.

## Reporting

Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a
vulnerability"). Do not open a public issue for a suspected vulnerability.

Include the package version, a minimal config that reproduces the problem and what you observed.
You will get a reply as soon as possible. Fixes ship as a patch release and are noted in
`CHANGELOG.md`; the report is credited there if you want it to be.

## Supported versions

The latest published minor of the current major receives fixes.
